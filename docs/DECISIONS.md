### D007 — 基线选型：TransReID 为主，CLIP-ReID 为对比

### D008 — 统一数据接口：manifest + Market1501 兼容目录

- **日期**：2026-10-27
- **状态**：已采纳
- **背景**：三个数据集格式不同，上游代码只认 Market1501 目录；需要让数据、评测、基线解耦。
- **决策**：`src/reid/manifest.py` 定义 `(path, pid, camid)` 的 query/gallery/train 清单；Market1501 直接解析官方目录，Move/CCVID 后续转换为同样的 manifest 或 Market1501 兼容目录。
- **备选方案**：每个数据集改一份上游 dataloader；手工维护 txt 列表。
- **影响**：manifest 成为数据与评测的冻结接口；上游代码尽量不改，必要时用 `patches/`。
- **关联**：D009、D010

### D009 — 评测协议：mAP + CMC Rank-1/5/10

- **日期**：2026-10-27
- **状态**：已采纳
- **背景**：课程按 mAP、Rank-1、Rank-5 评分；需要与上游数字对齐。
- **决策**：主指标 mAP，辅助 Rank-1/5/10；对每个 query 剔除同 ID 同摄像头的 gallery 样本后排序；特征 L2 归一化后用余弦距离。本地 `src/reid/metrics.py` 与上游 `R1_mAP_eval` 对拍。
- **备选方案**：直接抄上游日志；只报 Rank-1。
- **影响**：`metrics.json` 是报告唯一数字来源；报告保留 1 位小数。
- **关联**：D008

### D011 — 4GB 显存策略：推理优先，训练另找算力

- **日期**：2026-10-27
- **状态**：已采纳
- **背景**：本机为 RTX 3050 Ti Laptop，仅 4GB 显存；ViT-B 训练按上游 batch 64 不可行。
- **决策**：主实验以预训练权重推理为主，batch 16–32；训练/调参类加分实验优先用 Colab，或改用更小模型/分辨率并记录偏差。
- **备选方案**：只用 CPU（极慢）；强行减小 batch 至 1。
- **影响**：B/C 的排期要预留权重下载与 Colab 环境；所有实验必须记录 GPU/环境。
- **关联**：D007

### D013 — 团队协作用 GitHub，共享仓库保持轻量

- **背景**：4 人小组将通过 GitHub 协作；个人本地配置不应进入团队仓库，课程作业也不需要完整的工程管理流程。
