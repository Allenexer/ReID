## 后续关键路径

1. **Market1501 全链路**：A 的 manifest → B/C 跑基线并保存 distmat/日志 → A 统一出数 → D 汇总。
2. **Move 适配（作业要求）**：修改 test.py 使两个基线可在课程测试集上运行；
   待课程数据发布后，由 A、B 确定目录结构与仅测试集方案。
3. **CCVID（加分项）**：C 先实现单帧基线，再推进至多帧聚合。
4. **训练/调参（加分项，B 主线）**：使用 Market1501 训练集，训练在 Colab 进行；
   先以单 batch 冒烟测试验证流程，再全量训练；设置断点续训以应对
   免费会话时长限制。
5. **线性分类器实验（作业推荐方法，D）**：query 与 3 候选的相似度及匹配概率；
   由 D 实现，结果作为报告中的补充实验。
