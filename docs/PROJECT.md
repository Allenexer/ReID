## 2. 问题定义

- **任务类型**：图像检索 / 行人重识别（Person Re-Identification）
- **目标**：给定一张（或一组）查询行人图像，在候选图库中按身份相似度排序，让同一 ID 的图片尽量靠前。
- **输入**：query 图像；gallery 图像库。
- **输出**：按相似度降序排列的 gallery 列表，以及 mAP、CMC（Rank-1/5/10）指标。
- **成功标准**：Market1501、Move、CCVID 三个数据集全部成功运行；指标可复现、可溯源；报告完整。
- **课程评分**：成功运行占 50%（三个数据集全跑通有加分）；评价指标占 50%（mAP、Rank-1、Rank-5 正确且高）。

## 3. 数据

| 数据集 | 来源 | 规模/划分 | 角色 | 本地路径 |
|---|---|---|---|---|
| Market1501 | Kaggle（课程给出链接） | 训练 751 ID / 12936 图；测试 750 ID / 3368 query | 主评测集，可训练 | `data/raw/market1501/` |
| Move | 课程提供 | 200 ID / 800 query，含遮挡 | 验证集，仅测试 | `data/raw/move/` |
| CCVID | GaitNet-CVPR2019 | 换衣视频 ReID，规模以官方为准 | 探索/加分 | `data/raw/ccvid/` |

规则：

- `data/raw/` 只读；所有转换由 `scripts/` 生成到 `data/processed/`。
- 数据集、压缩包、帧文件一律不入 git；小体积 manifest 可重新生成，默认也不入库。
- 数据来源、下载日期、校验和记录在 `data/README.md`；任何重新划分或版本变化记入 `DECISIONS.md`。
- Market1501 采用官方划分；评测时按惯例剔除同 ID 同摄像头的 gallery 样本。

## 4. 方法与基线

- **主基线**：TransReID（ViT-B/16，ImageNet 预训练 + Market1501 预训练权重），仓库固定 commit。
- **对比基线**：CLIP-ReID（ViT-B/16），仓库固定 commit。
- **加分方向**：
  1. 用 Market1501 训练集微调/调参，与官方权重对比；
  2. CCVID 换衣场景与 Move 遮挡场景的改进（多帧聚合、TTA、re-ranking、遮挡增强等）。
- **可选探索**：课程推荐的"线性分类器 + query/3 候选"小实验，用于分析特征判别性；不作为主线，避免挤占基线时间。
- **不做什么**：从零训练大模型；自建数据集；与 ReID 无关的检测/分割任务。

## 5. 评估

- **主指标**：mAP（mean Average Precision）。
- **辅助指标**：CMC Rank-1、Rank-5、Rank-10。
- **验证协议**：
  - 使用官方 query/gallery 划分；
  - 对每个 query，剔除 gallery 中同 ID 同摄像头的样本后排序；
  - 所有基线使用相同 manifest、相同距离度量（余弦距离，特征已 L2 归一化）；
  - 报告保留 1 位小数，原始值保留 6 位小数。
- **统计要求**：推理基线每个数据集至少完整跑 1 次；训练/调参实验跑 3 个种子，报告均值 ± 标准差。
- **基线验收**：Market1501 上主基线与上游 README 对应权重的报告值相差应 ≤1 个百分点；差距更大时先排查数据、权重和评测协议，再谈调优。

## 7. 约束与风险

- **算力**：RTX 3050 Ti Laptop，4GB 显存。推理可行（建议 batch 16–32）；ViT-B 训练大概率 OOM，训练类实验需 Colab 或缩小模型/分辨率。
- **时间**：课程截止日期 TBD，按 4–5 周排期。
- **主要风险**：
  - Move 数据布局未知，适配器需等数据发布；
  - CCVID 是视频数据，需要抽帧与 tracklet 聚合；
  - 上游代码较旧（Python 3.12 / PyTorch 2.x 兼容问题，已提供补丁）；
  - Google Drive / Kaggle 下载限速或需要账号；
  - 4GB 显存导致 batch 受限，影响调参空间；
  - 若 4 人共用本机，B/C 的推理任务需错峰；各自有机器或 Colab 更稳妥。
